# Пакет прайсов и правил Mebel-LAB

Дата сборки: 16.08.2026  
Назначение: передача Люде для проектирования ИИ-автоматизации предварительного расчёта мебели.

## С чего начать

1. Открыть `00_INDEX.md` — там описаны состав, происхождение и статус каждого блока.
2. Для машинной загрузки использовать `00_MACHINE_INDEX.json`.
3. Основной рабочий справочник цен — `01_core/master_price.xlsx`.
4. Правила применения цен — `01_core/pricing_rules.md`, но этот файл смешивает правила разного статуса. Перед автоматизацией обязательно использовать классификацию `06_internal_rules/RULE_CLASSIFICATION.md`.
5. Общие правила процесса и структуры результата — `01_core/MEBEL_LAB_PROJECT_RULES.md`.
6. Официальные первоисточники всегда имеют приоритет над пересказами и внутренними допущениями.

## Ключевой принцип для ИИ

Нельзя превращать все записи в один равноправный набор правил. Для каждой записи хранить минимум:

- `authority`: кто является источником;
- `scope`: к какой фабрике или ко всем расчётам относится;
- `status`: официальный факт, пояснение сотрудника/партнёра, универсальное правило процесса, внутреннее консервативное допущение или проектное решение;
- `effective_date`: дата источника;
- `source_file`: файл, по которому утверждение можно проверить;
- `requires_confirmation`: требуется ли проверка перед применением.

## Ограничение комплекта

Это рабочий экспорт на указанную дату, а не автономная производственная система. Он предназначен для предварительных расчётов. Точную деталировку, раскрой и производственную документацию должен делать технолог фабрики.
