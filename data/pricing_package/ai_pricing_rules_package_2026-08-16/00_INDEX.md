# Реестр передаваемого пакета

## Классы источников

| Код | Класс | Как применять |
|---|---|---|
| `FACTORY_OFFICIAL` | официальный прайс или ТУ конкретной фабрики | применять только к указанной фабрике и на дату документа |
| `FACTORY_MANAGER` | письменное пояснение менеджера фабрики | применять к указанной фабрике; при конфликте новый официальный документ выше по приоритету |
| `ANNA_PRACTICE` | практические пояснения Анны | рабочий ориентир, но не официальный документ фабрики |
| `TEAM_CONFIRMATION` | сведения Бориса/Павла/Анны о фактическом процессе | хранить как подтверждение команды; не выдавать за заявление фабрики |
| `UNIVERSAL_PROCESS` | общие правила предварительного расчёта Mebel-LAB | применять независимо от фабрики, если конкретный источник не устанавливает иное |
| `INTERNAL_CONSERVATIVE` | наше консервативное расчётное допущение | применять только с явной пометкой и возможностью замены после подтверждения |
| `PROJECT_SPECIFIC` | решение конкретного клиентского проекта | не переносить автоматически на других клиентов |
| `HISTORICAL_METHOD` | старый учебный материал | использовать для понимания метода; старые цены не применять |

## Состав папок

### `01_core`

| Файл | Что содержит | Основной статус |
|---|---|---|
| `master_price.xlsx` | нормализованный рабочий справочник цен «Ренессанса» | производный рабочий справочник; сверять с официальными PDF |
| `pricing_rules.md` | алгоритм расчёта, ставки, правила листовой оценки, кромки, ящиков, радиусов и проектные решения | смешанный; использовать только вместе с классификацией |
| `MEBEL_LAB_PROJECT_RULES.md` | универсальный рабочий процесс: входные данные, расчёт, КП, доставка/монтаж, визуальная проверка, версии и источники | `UNIVERSAL_PROCESS`; копия корневого `AGENTS.md` на дату экспорта |
| `factories.md` | реестр фабрик, подтверждённые и неподтверждённые возможности | смешанный реестр фактов и статусов проверки |
| `change_log.md` | история поступления и изменения источников | служебный аудит |
| `README.md` | устройство исходной папки `pricing/` | навигация |
| `source_manifest.sha256` | контрольные суммы исходного набора на дату его формирования | проверка целостности исходников; не заменяет новый манифест экспорта |

### `02_renaissance_official_prices`

Официальные PDF-прайсы «Ренессанса»: корпусные материалы, фасады, кромка, фурнитура, подсветка, стекло, столешницы, профили и специальные изделия.  
Статус: `FACTORY_OFFICIAL`. Область: только «Ренессанс». Наименования файлов указывают товарную группу. Дата актуальности рабочего набора согласно `pricing_rules.md` — 03.07.2026; перед длительным использованием автоматизации дату необходимо перепроверять.

### `03_renaissance_technical_conditions`

- `README.md` — навигация и правила чтения ТУ;
- `2026/Тех характеристики 26,03,26.pdf` — общие технические характеристики фасадов и специальных исполнений;
- `2026/Шпон 15,06,26.pdf` — ТУ по Fine-Line/шпонированным изделиям;
- `2026/Шпонированные фасады новые.pptx` — технологическая памятка по натуральному шпону и специальным исполнениям.

Статус: `FACTORY_OFFICIAL`. Ограничения относятся только к «Ренессансу» и к конкретному материалу/типу детали, а не ко всем фабрикам.

### `04_dream_official`

- `2026-08-12_materials/Материалы Dream_Mebel 2026 г. (3).pdf` — основной присланный прайс материалов и операций;
- файлы `AGT`, `ALVIC`, `Egger`, `Kronospan`, `Fenix` — соответствие декоров ценовым категориям;
- `МДФ Пленки Исключения...pdf` — доплаты и исключения по плёнкам;
- `Складские декоры 18мм.xlsx` — перечень складских декоров;
- оба `README.md` — проверенное описание состава, границ знания и плана индексации.

Статус PDF/XLSX: `FACTORY_OFFICIAL` в смысле файлов, переданных фабрикой; точную редакцию и срок действия всё равно надо контролировать. Статус README: производная аналитическая запись Mebel-LAB. Публичные сведения о Dream в `2026-08-06/README.md` не заменяют ТУ и договорные условия.

### `06_internal_rules`

`RULE_CLASSIFICATION.md` — разделение накопленных правил по происхождению и области применения. Это главный файл для проектирования логики ИИ, но не первоисточник цен.

## Что сознательно не включено

- клиентские расчёты и КП, включая проект Ольги: это примеры применения, а не общая нормативная база;
- `pricing/raw/renaissance/knowledge_base/` — крупная веб-выгрузка с кэшами, изображениями и внешними материалами;
- папки `processed/`, превью, OCR и временные индексы;
- примеры фабричных расчётов прошлых периодов: они не являются актуальным прайсом;
- файлы из Downloads: в пакет вошли рабочие копии из `pricing/`.

Полный исходный рабочий корпус остаётся в `C:\Users\user\Documents\Мебельный бизнес\pricing`.
