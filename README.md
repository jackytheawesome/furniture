# КорпусСмета

Веб-сметчик встраиваемой корпусной мебели: быстрая прикидка по рендеру, подробная смета, демо-прайс, подсказки для новичка и экспорт в Excel.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Что умеет MVP

- **Смета** — быстрый режим (погонные метры, фасады, ящики, техника) и подробный редактор строк
- **Прайсы** — демо-цены, правка, импорт CSV/Excel, шаблон CSV
- **Справочник** — термины: что / где / зачем / как сэкономить
- **Excel** — листы «Клиенту», «Внутреннее», «Подсказки»

Данные хранятся в `localStorage` браузера. AI-распознавание рендеров — не в этом релизе.

## Импорт прайса

Колонки CSV: `id`, `category`, `name`, `unit`, `price`, `note`, `helpKey`.

Категории: `board`, `facade`, `edge`, `hardware`, `countertop`, `labor`, `other`.  
Единицы: `m2`, `lm`, `pcs`, `set`, `job`.
