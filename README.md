# КорпусСмета

Сметчик корпусной мебели: мультилогин, проекты, корзина предметов, автостроки, чеклист, импорты CSV/PDF, экспорт Excel/PDF.

**Полная документация для доработок:** [docs/KORPUS_SMETA.md](docs/KORPUS_SMETA.md)

## Быстрый старт

```bash
npm install
npx prisma migrate dev
npx prisma db seed
npm run dev
```

Откройте http://localhost:3000 (или порт, который укажет `next dev`).

Для проверки production-сборки локально часто используют порт **3001**:
`npm run build && npm run start -- -p 3001` — помните, что `next start` не hot-reload’ит исходники.

**Демо-пользователи**
- `demo@korpus.local` / `demo123`
- `admin@korpus.local` / `admin123`

## Возможности

- Проекты на пользователя
- Каталог: кухня / корпусная / спальня / нестандарт → параметры → корзина
- Автостроки (корпус, фасады, кромка, фурнитура, работы) + ручные статьи
- В смете: статьи из прайса/произвольно по блокам; выбор плиты (корпус/ХДФ) из прайса с пересчётом
- Наценка, общие статьи (доставка/монтаж)
- Чеклист самопроверки + подсказки
- Версии сметы (черновик / клиенту)
- Импорт CSV/Excel (в т.ч. PRO100 список деталей) и PDF дизайнера
- Экспорт Excel (внутренний/клиент) и PDF с уровнем точности

Картинки-схемы пока не рисуются; в модели есть `visualHints` под будущее.

## Прайсы Ренессанс

```bash
npm run prices:import-renaissance
```

Курируемые ставки движка: `src/lib/renaissance-defaults.ts`.  
Пакет и нормализованный CSV: `data/pricing_package/`.

## Стек

Next.js 16, Auth.js, Prisma 5 (SQLite локально), ExcelJS, pdf-parse, @react-pdf/renderer.
